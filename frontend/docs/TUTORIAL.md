# 新手教程

入口为 `/tutorial`（需要登录），页底提供“新手教程”按钮。登录后进入主页，未提示过的账号会收到一次邀请；新账号和升级前的旧账号使用相同判断。收到邀请、推进教程或完成教程后，不重复自动邀请。

## 五步体验

1. 先显示正式 HomePage，引导输入 RAG 并点击“开始寻路”，再完成五个前置知识点的自评，复用 QuestionPanel 和 StatusRail。教程主页只接受 RAG，不调用创建寻路接口。
2. 点击示例图谱的文本分块节点。
3. 选中重叠分块的句子，查看预先准备的解释，保存到示例疑惑本。提供“使用示例句子”作为触屏和键盘替代入口。
4. 回看示例疑惑并标记理解。
5. 收藏知识点、打开示例收藏，再完成教程。

示例内容位于 `src/components/reading/tutorialExample.ts` 和 `tutorialServices.ts`。图谱为三层六个节点：文本分块、词嵌入、提示词 → 向量检索、上下文组织 → RAG，只有五个前置节点。

结果复用 ResultOverview、PathView 和 ResourcesDrawer，侧栏继续使用正式 NodeOverview 和 ReadingModal。疑惑本与知识卡片直接渲染 DoubtsPage 和 KnowledgeCardsPage，包括票券、筛选及详情弹窗。ReadingServicesContext 默认使用真实 API；仅教程 Provider 注入独立内存演示服务，不修改全局 API 或用户记录。教程未调用生成模型或知乎搜索。

## 数据边界

教程使用 Ant Design Tour 聚光引导：整页遮罩变暗，当前操作区域挖空高亮，旁边显示提示。高亮区域可直接输入、点击和选字，完成操作后自动选择下一处目标；支持 Drawer/Modal 中的操作及手机布局。可以暂停后自由浏览，再恢复引导，或退出教程。遮罩颜色来自 theme.ts；提示定位容器禁用过渡，避免减少动态效果的全局规则干扰定位测量。

`GET /api/v1/tutorial` 返回当前账号的 `{ step, prompted, revision }`。
`PATCH /api/v1/tutorial` 接收 `{ action, revision }`，action 为 seen、advance 或 reset，需要登录与 CSRF。账号由服务端会话决定，不接受客户端指定账号。revision 采用比较后更新，旧请求返回 409，防止重试或多标签页重复推进。

V13 增加独立 tutorial_progress 表，记录提示状态、已完成步骤数、修订号和完成时间。不存在进度行时返回未提示的零进度，因此旧用户不需要批量初始化。教程没有任何真实寻路、节点、疑惑或收藏 ID，也不写业务表。

完成一步后保存进度，刷新或换设备会恢复到下一步。当前步骤中的选项、示例弹窗和收藏尝试是临时状态，重进本步骤可重新体验。完成后的页底入口仍可重新开始；重置不影响个人业务记录。

自动邀请仅在主页出现，避免打断正在答题或阅读的用户。教程完成情况不计入站点学习记录或生成额度。

## 验证

后端 TutorialIntegrationTest 验证鉴权、CSRF、账号隔离、非法操作、重复请求冲突、重置和业务表零写入；FlywayMigrationTest 验证升级与重复启动。

桌面和 390px 窄屏验证邀请、刷新续学、保存失败后重试、完成后不再邀请及重置。桌面使用浏览器选区触发共享工具栏，窄屏使用示例句子入口。验证期间拦截业务接口，确保教程不发起真实学习请求。
# 引导定位与回看验收

四个阅读场景先介绍内容，再引导操作：节点侧栏依次介绍知识点卡片、相关资料，再提示关闭；句子解释先介绍解释正文，再提示保存；疑惑详情先回看原句与解释，再标记已理解；收藏详情先介绍完整讲解，再提示关闭。介绍由用户点击“下一步”推进，不使用定时跳过，阅读期间可滚动。

引导层在独立固定容器内渲染，不锁定页面滚动。遮罩允许滚轮和触屏滑动穿透到页面或阅读容器；点击捕获仅放行当前高亮目标及教程操作，避免误触其他按钮。滚动过程中持续测量目标，高亮始终跟随同一元素，不固定在错误的屏幕坐标。

教程切换阶段或列表时先回到页面顶部；目标不在视口时仅滚动页面或真实的阅读滚动容器，不调用目标元素的 `scrollIntoView`，避免带动票券内部的隐藏溢出容器。高亮使用实时测量的独立目标，跟随侧栏、弹窗动画和内部滚动更新。答题提示固定在顶部，并将题目及选项一起高亮。

最后一步必须在知识卡片列表打开已收藏卡片，回看详情后才可完成教程。此操作仍使用教程独立数据服务，不写入个人收藏。
