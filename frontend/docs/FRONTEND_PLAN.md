# 前端实施与验收计划

更新日期：2026-09-12。本文保留交付目标与验收门槛；当前实现见 [FRONTEND.md](FRONTEND.md)，详细遗留项见 [接口待办](FRONTEND_API_TODO.md)。已过时的工期估算和重复差距表不再作为执行依据。

## 产品范围

一个登录页、三个业务页面及资料抽屉。流程为目标生成图谱和问卷、本地自评、提交后检索资料、展示完整图谱。自评不是考试，不提供能力分数；已掌握节点保留，资料推荐按四档上限处理。

## 验收矩阵

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| A01 | 空输入、边界长度、连续创建 | 无效输入不创建，提交期间不重复请求，失败可修改输入 |
| A02 | 生成、搜索及 FAILED | 阶段准确；模型失败分类明确；搜索使用真实节点进度 |
| A03 | 自评、返回与清空 | 选择仅本地保存；清空全部答案不发后端写请求 |
| A04 | 复核及再次提交 | 可从目录修改；全部 PUT 成功后才 complete；失败保留本地选择 |
| A05 | 零前置与全部非常了解 | 零前置提示补充目标；全部非常了解仍保留完整图谱 |
| A06 | 并行与跨层边 | 保留原始 edges，连线不穿卡片，不增加假依赖 |
| A07 | 六个同层、21 节点、长名称 | 每行至多五个，换行不改变 level，所有节点可访问 |
| A08 | 资料状态与缺失字段 | 状态、数量及操作真实；null 不冒充 0，不补造资料 |
| A09 | 切任务、离页、退出 | 不残留旧状态，不继续剩余提交或由旧完成响应导航 |
| A10 | 刷新与直接访问子路由 | 恢复服务端状态；未提交草稿不承诺恢复；生产无 SPA 404 |
| A11 | 401/403/404/409/429、断网 | 提示和恢复明确；待实现的退避策略完成后验证 |
| A12 | 不同用户访问同一任务 | 服务端拒绝越权，不展示其他用户数据 |
| A13 | Mock/API 构建 | Mock 标识明确，API 不静默回退，浏览器无上游密钥 |
| A14 | 390px、桌面、键盘、减少动态 | 核心操作完整，焦点可见，图横滚仅限容器 |

记录版本、环境、预期、实际结果和截图或日志。自动化逻辑测试不能替代真实浏览器及服务联调。

## 检查与发布

```powershell
cd frontend
npm ci
npm run lint
npm run typecheck
npm run test:regressions
npm run test:loading
npm run build
```

现有测试使用 Node test runner；尚未建立完整浏览器 E2E 套件。新增工具前先明确验收收益，不把计划写成已实现能力。

发布前需完成认证与 CSRF、真实主链路、子路由刷新、数据隔离和无假资料验证，并记录可回退构建。CI 与部署工作流以 `.github/workflows` 为准；前后端兼容性需覆盖发布顺序。配置见 [部署说明](../../docs/DEPLOYMENT.md)。

## 性能与后续范围

保留路由懒加载；评估每节点描述/数量读取及抽屉重复读取的开销，测量后再决定缓存或批量接口。记录固定设备、网络和浏览器下的首屏及操作响应，LCP≤2.5s、INP≤200ms、CLS≤0.1 仅为候选目标，不是当前成绩。模型耗时单独统计。

图缩放、导出、分享、重新搜索、持久化草稿、原子批量提交和知乎 OAuth 属于后续范围；实施前另行确定需求与接口。
