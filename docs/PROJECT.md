# 知阶 Knowledge Steps 项目计划书

## 一、项目定位

**项目名称：** 知阶 Knowledge Steps  
**参赛赛道：** 知识炼金场：学习工具与知识生产  
**品牌标语：** 每一个知识，都有它的台阶。  
**产品介绍：** 告诉我你想学什么，我只告诉你还缺什么。

知阶是一款轻量的知识寻路工具，面向**希望学习新知识、但不清楚前置要求的学生与自主学习者**。
> 说白了就是用户想学习新知识，我们能给他们提供这个新知识的前置知识
> 首先将用户输入的知识发给一个轻量化模型，通过提示词让其输出这个知识的前置知识节点
> 然后将所有的前置节点分层，然后将每个节点通过 知乎 搜索 API 去搜索出数据
> 但是不要把所有的数据全给用户，要不然太乱了
> 先给用户生成一个答卷，答卷的问题交给另一个轻量化模型通过所有前置节点分别生成
> 用户填写答卷 遇到知道的知识则将其搜索到的数据抛出
> 最后答卷结束，将剩余的用户不知道的知识呈现给用户

用户输入目标知识后，系统推导必要的前置知识，通过简短问答了解用户基础，隐藏已经掌握的内容，最终生成需要补齐的知识路径。每个知识节点关联知乎学习资料，让用户可以直接开始学习。

首版采用 **3 个页面 + 1 个资料侧栏**，不设置打卡、学习时长或个人 Dashboard。

## 二、首页：输入学习目标

**页面目的：让用户明确“我想学什么”，快速开始寻路。**

主要内容与功能：

- 展示产品名称、标语和学习目标输入框。
- 支持输入知识名称，例如 Transformer、RAG、Spring Boot。
- 提供热门知识快捷入口，点击后自动填入目标。
- 点击“开始寻路”，生成候选前置知识，并进入问答页。
- 展示生成中的状态；输入过于模糊时，提示用户补充目标。
- 生成失败时提供重试入口，保留已经输入的内容。

首版优先覆盖少量准备充分的主题，保证知识结构和资料质量。

## 三、问答页：识别已有基础

**页面目的：通过少量问题，找出用户尚未掌握的前置知识。**

左侧展示当前问题，例如：

> 你了解矩阵乘法吗？

提供四个选项：

**非常了解 / 基本了解 / 听说过 / 不了解**

主要功能：

- 按固定题目顺序逐题自评，每个前置节点一道题，目标不出题。
- “非常了解”和“基本了解”均记为已掌握，第一版不追加确认题。
- “听说过”和“不了解”记为需要补齐。
- 支持返回上一题修改答案，并更新后续判断。
- 右侧展示轻量状态列表：已掌握、待补齐、正在确认、尚未确认。
- 完成必要确认后，进入结果页。

这里不展示能力分数或准备度百分比。判断以用户自述和有限确认题为依据，不包装成严格的能力测评。

## 四、结果页：展示需要补齐的知识路径

**页面目的：清楚回答“以我现在的基础，还差哪几步”。**

例如：

> 学习 Transformer，你还需要补齐 2 个前置知识。

```
Attention
    ↓
Self-Attention
    ↓
Transformer（目标）
```

主要功能：

- 隐藏已掌握的节点，只展示待补齐的知识和最终目标。
- 按前置依赖排列学习顺序，保留必要的并行分支，不强行拼成直线。
- 明确区分“待补齐知识数量”和“目标知识”，避免重复计数。
- 点击节点打开资料侧栏。
- 支持返回修改基础判断，或重新输入学习目标。
- 如果前置知识都已掌握，提示“可以开始学习目标知识”，只展示目标；第一版不搜索目标资料。

## 五、资料侧栏：连接知乎内容

**页面目的：让每个知识节点都成为可以立即使用的学习入口。**

点击结果页的知识节点后，在右侧打开资料侧栏，包含：

- **知识名称与简要解释：**帮助用户理解这个节点是什么。
- **学习它的原因：**说明它与目标知识的关系。
- **知乎学习资料：**展示相关内容的标题、摘要，以及接口实际返回的作者、赞同数等信息。
- **原文入口：**点击后在新标签页打开知乎原文。

每个节点优先呈现少量相关资料，避免堆积搜索结果。没有合适资料时明确提示，不生成虚假的来源或互动数据。

## 六、核心实现与创新点

整体流程为：

**输入目标 → 推导前置知识 → 关联知乎资料 → 问答确认 → 精简路径 → 点击节点学习**

技术上采用 React、TypeScript 和 Ant Design 构建前端；Java、Spring Boot 提供接口，SQLite 保存知识结构及缓存。大模型负责生成候选知识依赖与解释，知乎官方搜索能力负责提供学习资料，服务端负责去重、排序、依赖检查和路径精简。

核心创新在于：

1. **根据个人基础精简知识结构。** 同一个学习目标，不同用户会得到不同的待补齐清单。
2. **将复杂图谱转化为简单问答。** 先确认基础，再展示必要路径，降低理解成本。
3. **把知识节点与知乎内容连接。** 用户既能知道缺什么，也能找到从哪里开始学。

路径精简只隐藏已掌握节点，不破坏必要的依赖关系。项目的最终价值，是帮助用户更快找到学习起点，把“想学却不知道怎么开始”转化为明确的下一步。
