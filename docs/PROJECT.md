# 知阶 Knowledge Steps 项目计划书

## 一、项目定位

**项目名称：** 知阶 Knowledge Steps  
**参赛赛道：** 知识炼金场：学习工具与知识生产  
**品牌标语：** 每一个知识，都有它的台阶。  
**产品介绍：** 告诉我你想学什么，我只告诉你还缺什么。

知阶是一款轻量的知识寻路工具，面向**希望学习新知识、但不清楚前置要求的学生与自主学习者**。
当前顺序：模型 A 生成图谱，后端校验并分层，模型 B 为前置节点生成自评题；用户确认全部选择后保存答案，再按熟悉程度搜索资料。结果保留全部节点和依赖，不隐藏已掌握内容。

用户输入目标知识后，系统推导必要的前置知识，通过简短问答了解用户基础，保留完整知识关系并按熟悉程度推荐资料，最终生成需要补齐的知识路径。每个知识节点关联知乎学习资料，让用户可以直接开始学习。

首版采用 **1 个登录页 + 3 个业务页面 + 1 个资料侧栏**，不设置打卡、学习时长或个人 Dashboard。

## 二、首页：输入学习目标

**页面目的：让用户明确“我想学什么”，快速开始寻路。**

主要内容与功能：

- 展示产品名称、标语和学习目标输入框。
- 支持输入知识名称，例如 Transformer、RAG、Spring Boot。
- 提供热门知识快捷入口，点击后自动填入目标。
- 点击“开始寻路”，生成候选前置知识，并进入问答页。
- 展示生成中的状态；输入过于模糊时，提示用户补充目标。
- 生成失败时提供重试入口，保留已经输入的内容。

首版优先覆盖少量准备充分的主题，保证知识结构和资料质量。

## 三、问答页：识别已有基础

**页面目的：通过少量问题，找出用户尚未掌握的前置知识。**

左侧展示当前问题，例如：

> 你了解矩阵乘法吗？

提供四个选项：

**非常了解 / 基本了解 / 听说过 / 不了解**

主要功能：

- 按固定题目顺序逐题自评，每个前置节点一道题，目标不出题。
- “非常了解”记为已掌握，不推荐资料；“基本了解”建议巩固，最多推荐 2 条资料。
- “听说过”和“不了解”记为需要补齐，分别最多推荐 3 条和 5 条资料。
- 支持返回上一题修改答案，并更新后续判断。
- 右侧按题目顺序展示目录，标记当前题与已答状态，不显示熟悉程度标签。
- 选择暂存在页面；支持提交前清空全部选择，点击“查看结果”后逐题保存并启动资料搜索。
- 完成必要确认后，进入结果页。

这里不展示能力分数或准备度百分比。判断以用户自评为依据，不包装成严格的能力测评。

## 四、结果页：展示需要补齐的知识路径

**页面目的：清楚回答“以我现在的基础，还差哪几步”。**

例如：

> 学习 Transformer，你还需要补齐 2 个前置知识。

```
Attention
    ↓
Self-Attention
    ↓
Transformer（目标）
```

主要功能：

- 展示全部节点和最终目标，非常了解的节点不附资料，其余按 2/3/5 条上限推荐。
- 按前置依赖排列学习顺序，保留必要的并行分支，不强行拼成直线。
- 明确区分“待补齐知识数量”和“目标知识”，避免重复计数。
- 点击节点打开资料侧栏。
- 支持返回修改基础判断，或重新输入学习目标。
- 全部选择非常了解时仍展示完整图谱，目标不搜索资料；若生成零前置节点，提示用户补充目标或重试。
- 前端同一逻辑层每行最多五个节点，超出换行；淡蓝色直角折线避让卡片，无箭头和圆点，卡片持续显示。

## 五、资料侧栏：连接知乎内容

**页面目的：让每个知识节点都成为可以立即使用的学习入口。**

点击结果页的知识节点后，在右侧打开资料侧栏，包含：

- **知识名称与简要解释：**帮助用户理解这个节点是什么。
- **学习它的原因：**说明它与目标知识的关系。
- **知乎学习资料：**展示相关内容的标题、摘要，以及接口实际返回的作者、赞同数等信息。
- **原文入口：**点击后在新标签页打开知乎原文。

每个节点优先呈现少量相关资料，避免堆积搜索结果。没有合适资料时明确提示，不生成虚假的来源或互动数据。

## 六、核心实现与创新点

整体流程为：

**输入目标 → 推导前置知识 → 生成自评题 → 自评提交 → 按熟悉程度搜索资料 → 查看完整图谱并学习**

技术上采用 React、TypeScript 和 Ant Design 构建前端；Java、Spring Boot 提供接口，SQLite 保存知识结构及缓存。大模型负责生成候选知识依赖与解释，知乎官方搜索能力负责提供学习资料，服务端负责去重、排序、依赖检查和资料数量控制。

核心创新在于：

1. **根据个人基础确定学习重点。** 同一个学习目标，不同用户会得到不同的待补齐清单。
2. **将复杂图谱转化为简单问答。** 先确认基础，再展示必要路径，降低理解成本。
3. **把知识节点与知乎内容连接。** 用户既能知道缺什么，也能找到从哪里开始学。

结果保留全部节点及依赖，通过熟悉程度区分学习重点。项目的最终价值，是帮助用户更快找到学习起点，把“想学却不知道怎么开始”转化为明确的下一步。
