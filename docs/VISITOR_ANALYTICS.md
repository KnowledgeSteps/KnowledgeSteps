# 访问统计（UV / PV / 独立 IP）

本功能已在本地实现，尚未部署。前端使用 Ant Design + 按需引入的 ECharts，后端继续使用 SQLite；没有接入第三方采集脚本，不调用模型或知乎接口。

## 使用方式

管理员登录后点击顶栏“访问统计”（`/admin/analytics`）。普通知乎用户不可查看，后端独立校验管理员身份，不依赖昵称或前端按钮隐藏。

- 顶部切换“数据图表 / 访问记录”，选择最近 30 天内的日期，默认近 7 天。
- 数据曲线支持折线与列表切换；CSV 导出所选日期的每日 PV、UV、IP。
- 地区分布支持中国省级地图、世界地图以及 Top 10 列表。24 小时、一周、操作系统、浏览器分布按访问次数展示。
- 高频 IP 使用按日匿名标识；访问记录显示时间、粗粒度页面类型、归属地和设备类别，最多保留最近 5000 条、每页 20 条。
- “分享数据”仅打开汇总摘要供复制，不创建公开链接，不包含访问明细。没有自动向任何人发送数据。
- 空状态、读取失败重试、地图加载失败、导出、键盘焦点和手机单栏均已适配。未采集的历史不能回补。

## 统计口径

全部日期和小时按 `Asia/Shanghai` 计算。

| 指标 | 规则 |
| --- | --- |
| UV | 按第一方浏览器 Cookie 每日去重，同浏览器登录前后共用标识 |
| PV | 页面停留超过 300ms 后上报一次；进入、刷新、前进后退和切换页面产生访问 |
| 独立 IP 数 | 可信直属代理解析出的来源地址每日去重，未知地址不计 IP |
| 小时 / 星期 | 所选日期内 PV 按北京时间小时或星期合并 |
| 系统 / 浏览器 | 对 User-Agent 做有限类别识别，不能保证识别所有内嵌浏览器 |
| 地区 | 本地离线 IP 库推断的国家和省级地区，不是 GPS 位置 |

仅采集首页、登录、历史、问卷、结果五类页面。API 轮询、资源加载、404、统计后台不计 PV；管理员登录后的访问不计入。React StrictMode 重放及短暂跳转合并；同 Cookie 的同一事件 ID 在 10 分钟内重复提交只计一次，维度与明细也不重复增加。

UV 是浏览器数的近似，不是真实人数。清除或禁用 Cookie、更换设备可能重复计数；共享网络可能多人共用 IP，代理也会改变 IP。跨天标题明确标为“日访客数 / 日 IP 数合计”，不是区间去重人数。拦截器、DNT/GPC、网络失败或限流会少计，不能用于计费或审计。

地图未匹配的地区仍显示在列表中，未知和内网地址不着色；省份百分比以所选日期全部 PV 为分母，省份 Top 10 之和不必等于 100%。地区数据库和地图边界名称/更新日期可能不一致。

## 数据与保护

- Cookie `KST_VISITOR` 为随机 UUID，HttpOnly、SameSite=Lax、Path=/、有效期一年；生产配置继承安全会话 Cookie 的 Secure=true。
- 客户端只发送固定页面类型和随机事件 ID，不发送完整 URL、查询参数、OAuth code、寻路 ID 或学习目标。
- SQLite 保存每日 PV、按日 HMAC-SHA256 处理的 UV/IP 去重摘要、短期幂等摘要及粗粒度维度。高频来源只显示摘要前缀加日期，不保存明文 IP 或完整 User-Agent。每日密钥输入包含日期，不能根据标识跨天串联 IP。
- 明细最多 5000 条，包含时间、页面类别、按日匿名 IP 标识、国家/省份、系统和浏览器；不包含登录用户 ID。截断明细不影响完整聚合计数。
- 聚合及去重数据保留最近 30 个北京时间自然日；访问时清理，每小时也清理一次（启动一分钟后首次），边界清理最多延迟一小时。幂等收据有效期 10 分钟，同样随访问或维护清理。停机期间不清理。
- 现有 Nginx 安全访问日志仍保留来源 IP，属于独立运维日志，不代表统计数据库保存明文 IP。
- 尊重 DNT=1 与 GPC；采集超时或失败静默结束，不自动重试、不触发退出或影响寻路。登录页说明采集范围。
- 写入仅接受 JSON 与自定义请求头，拒绝跨站 Fetch Metadata；默认不开放跨域 CORS。匿名统计不创建登录会话。
- 写库前限制每来源每固定分钟最多 60 次、全站最多 300 次。Nginx 模板额外限制采集入口每 IP 平均 60 次/分钟、突发 10 次；这些是演示容量保护，不保证识别机器人。
- 地区查询发生在写事务之前。SQLite 短事务先取写锁，计数、维度和明细原子提交；统计不占模型工作线程，不创建无界队列。

如启用 Cloudflare 代理，需先在 Nginx 正确恢复并验证真实 IP 来源；否则 IP 统计会显示代理地址。后端仅信任配置的直属代理覆盖的 X-Real-IP。

## 地区数据与静态资源

离线库使用 [ip2region 官方数据](https://github.com/lionsoul2014/ip2region/tree/master/data)，客户端 3.3.7，包含 IPv4 和 IPv6。启动时提取至私有临时目录，使用向量索引缓存、每个协议两个搜索器；不把约 48MB 原始数据库全量加载到 Java 堆内存。正常关闭时删除临时文件，不在启动或查询时下载数据。原始 IP 不会发给第三方。数据来源、SHA-256 和 Apache-2.0 / MIT 许可证保留在 `backend/src/main/resources/geo`。

地图几何分别来自阿里云 DataV 和 Apache ECharts 示例，保存在 `frontend/public/maps` 并附 SOURCES.md；按需从本站加载。曲线、柱状图与地图使用 SVG 渲染，图表依赖只在管理员页面加载。更新离线库或地图必须重新核对哈希并运行测试，生产不自动更新。

## 接口与发布

- `POST /api/v1/analytics/pageviews`：匿名采集；X-Ksteps-Analytics: 1；JSON 为 page（固定类别）和 eventId（UUID）；204 成功，400 非法输入、403 来源拒绝、429 容量不足。
- `GET /api/v1/analytics/summary?start=YYYY-MM-DD&end=YYYY-MM-DD`：仅管理员；返回 timezone、days（day/pv/uv/ip）、hours/countries/regions/systems/browsers/ips（name/value）。默认最近 30 天，日期超范围或倒置返回 400。
- `GET /api/v1/analytics/visits?start=YYYY-MM-DD&end=YYYY-MM-DD&page=1`：仅管理员；返回 total/page/pageSize/items，每页 20 条，未登录 401、普通用户 403。
- 认证响应含 role（ADMIN/USER），只控制前端入口，后端查询真实身份命名空间授权。统计读取不缓存。
- Flyway V8 添加基础统计四表；V9 增加维度及明细两表。与已有用户、寻路无外键关系，删除寻路不改变统计。发布前备份，先部署后端，再部署前端和地图资源，校验 Nginx。
- 发布回退需考虑 Flyway 对较新版本结构的验证，不能只替换旧 jar 就假定成功。备份含摘要和服务端 HMAC 密钥，沿用受限权限。
